contribution — no hard feelings, just flag it in an issue instead.

## How to contribute

1. Open an issue describing the bug/feature before large changes, so we
   can align on approach.
2. Branch off `experimental` — **not** `master`. All PRs should target
   `experimental` as well. `master` is kept stable and is only updated
   from `experimental` once changes are tested.
3. Keep PRs focused — one fix/feature per PR is easier to review.
